LANGBLUE · SERVER REST

سیاست شفاف Server Rest

Server Rest برای زمان‌بندی محدودیت‌های محتوای داخلی و مدیریت بار سامانه طراحی شده است؛ نباید به‌عنوان قطع دسترسی به کل وب‌سایت LangBlue استفاده شود. صفحهٔ اصلی، حساب مرکزی و مسیرهای عمومی سایت نباید با یک قفل زمان‌بندی‌شده از دسترس خارج شوند.

قواعد فعلی سیاست

۱۰۰ حسابحداقل تعداد حساب‌های ثبت‌شده برای واجدشرایط شدن پنجره
پنج‌شنبهزمان بررسی با منطقهٔ زمانی تهران
۷ روزفاصلهٔ بررسی تا تاریخ آزمون زمان‌بندی‌شده
۱۴ روزمدت پنجرهٔ Server Rest در صورت برقرار بودن شرط‌ها

پنجره فقط وقتی فعال می‌شود که تعداد حساب‌ها به آستانه برسد، آزمون زمان‌بندی‌شده وجود داشته باشد و شرط پنج‌شنبه/فاصلهٔ آزمون برقرار باشد. اگر شرط‌ها برقرار نباشند، پنجرهٔ تازه‌ای فعال نمی‌شود.

پس از پنجره

پس از پایان پنجرهٔ محدودیت داخلی، سامانه تا چرخهٔ واجدشرایط بعدی نباید با قاعدهٔ «هر دو هفته» دوباره محدود شود. سیاست، به‌تنهایی مجوز بستن کل وب‌سایت یا جلوگیری از ورود به حساب مرکزی نیست.

این صفحه توضیح عمومی سیاست است، نه پنل مدیریت. تغییر تاریخ آزمون یا اجرای بررسی دستی باید از مسیر مدیریتی مجاز انجام شود.
